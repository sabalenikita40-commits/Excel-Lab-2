# 📊 Excel Lab 2 – Formulas, Cell Referencing & Business Metrics

## 📌 Overview

This Excel Lab focuses on using Excel formulas, cell referencing, and functions to perform business-related calculations. The tasks demonstrate how Excel can be used to calculate and analyze important business metrics from data.

## 🛠️ Key Skills Used

* Excel Formulas
* Cell Referencing
* Excel Functions
* Business Metrics Calculations
* Basic Data Analysis

## 📋 Tasks Performed

* Applied different Excel formulas to perform calculations.
* Used relative, absolute, and mixed cell references.
* Applied Excel functions for data calculation and analysis.
* Calculated business metrics using formulas.
* Organized and analyzed the results in Excel.

## 💡 Tools Used

**Microsoft Excel**

## 🎯 Learning Outcome

Gained practical knowledge of Excel formulas, cell referencing, functions, and business metric calculations for basic data analysis.
